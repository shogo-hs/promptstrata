# 0005. レイヤーは全て任意。穴あきテンプレートではなくパーツの逐次連結で組む

- 状態: 採用
- 日付: 2026-08-22

## 文脈

合成の実装には2つの方法がある。決まった形のテンプレート文字列を用意して各レイヤーの
内容を埋め込む方法と、存在するレイヤーだけをパーツとして順に足していく方法。

## 決定

- **すべてのレイヤーを任意**にし、パーツの逐次連結で組む。ファイルが無ければそのレイヤーは
  無いものとして扱う。
- 各レイヤーの中のフィールドにも同じ規則を通し、書かれていない項目はその行ごと落とす。
- ただし `--channel voice` と明示指定したのにファイルが無い場合はエラーにする。

## 理由

テンプレート方式だと、レイヤーが欠けたときに空の節や宙に浮いた見出しが残る。プロンプトに
意味のない見出しが混ざるのは害でしかない。パーツ連結ならその状態が構造的に起こらず、
実装もテンプレート文字列を持たないぶん小さい。暗黙の省略（指定していない）と指定ミス
（指定したがファイルが無い）を区別するのは、後者を黙って無視すると本番で気づけないため。

## 結果

語彙だけ、ロールだけ、といった小さい構成から始められる。反面、出力の全体像が1つの
テンプレートを見れば分かる、という利点は失う。

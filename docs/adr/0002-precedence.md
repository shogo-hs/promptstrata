# 0002. 優先順位を固定し、プロンプト本文にも書く

- 状態: 採用
- 日付: 2026-08-22

## 文脈

レイヤーが増えると規則は必ず衝突する。チャネルの「URL を読み上げない」と役割の
「案内 URL を提示する」は同時に成り立たない。

## 決定

- 優先順位を 禁止事項 > チャネル > 手順 > 役割 > 語彙 に固定する。
- 強い制約を後ろの節に置いたうえで、合成後のプロンプト冒頭にも優先順位を明示的に書き込む。
- 存在するレイヤーだけを順位表に載せ、レイヤーが1種以下なら順位の節ごと出さない。

## 理由

順位を書かないとモデルが勝手に裁定し、どちらが勝つかが実行ごとに変わる。後ろに置く
だけでも前に書くだけでも取りこぼすので両方やる。順位を設定で変えられるようにはしない
（変えたい事例がまだ無く、変えられると衝突時の挙動が読めなくなる）。

## 結果

衝突時の挙動が読める。反面、順位そのものを変えたい利用者はライブラリの改修が要る。

## 書き方

各 ADR はこの形式を踏襲する。

```markdown
# NNNN. タイトル

- 状態: 採用
- 日付: YYYY-MM-DD

## 文脈
## 決定
## 理由
## 結果
```

番号は連番で振る。既存の ADR は書き換えず、決定を変えるときは新しい番号の ADR を
書いて置き換える（元の ADR の内容はそのまま残す）。

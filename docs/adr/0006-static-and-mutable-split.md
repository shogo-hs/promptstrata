# 0006. 固定部と可変部を分け、可変部を末尾に置く

- 状態: [0008](0008-no-runtime-state.md) で置き換え
- 補足: 前半（`built.text` をビルド時に一度だけ合成する）は有効。後半（可変部を持ち
  システムプロンプトの末尾に置く）は撤回した。プロンプトキャッシュが前方一致で効くため、
  システムプロンプトの末尾を書き換えると会話履歴のキャッシュまで落ちる。
- 日付: 2026-08-22

## 文脈

会話が進むと顧客の氏名や注文番号が判明する。これをシステムプロンプトに反映したいという
要求がある。

## 決定

- 合成結果を固定部（`built.text`）と可変部（`built.state(facts)`）に分ける。
- 可変部は必ず末尾に置き、`facts` が空なら空文字を返す。
- 可変部に入れるのはツールで裏が取れた事実だけとする。

## 理由

プロンプトキャッシュは先頭からの一致で効くため、名前が判明するたびに本文を作り直すと
そのたびにキャッシュが外れる。音声チャネルでは初回応答の遅延に直接効く。可変部を末尾に
固定すれば、差し替えても固定部のキャッシュは効いたまま。また、客が口頭で言っただけの
事実はモデルが会話履歴で見えているので書き戻す必要がなく、書き戻す価値があるのは
「確認済み」という印が要る事実だけ。

## 結果

利用者はキャッシュの区切りを固定部の直後に置けばよい。反面、可変部に何を入れるかの
判断は利用者側に残る。

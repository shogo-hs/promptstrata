# 0004. 依存を pydantic と PyYAML に限る

- 状態: 採用
- 日付: 2026-08-22

## 文脈

プロンプトのテンプレート化には Jinja2、CLI には Typer や Click を使うのが普通で、
どちらも検討した。

## 決定

- 依存は `pydantic>=2` と `PyYAML` だけにする。
- CLI は標準ライブラリの `argparse`、変数展開は標準ライブラリの `string.Template`
  （`$var` 形式）で書く。

## 理由

外部に配布するライブラリなので、利用者の依存ツリーに載るものを増やしたくない。現時点で
必要なのは変数の差し込みだけで、条件分岐やループは要らない。`string.Template` で足りる。
`argparse` で足りる CLI に Typer を足す理由がない。pydantic はスキーマ検証とエラー
メッセージのために入れる（自前で書くほうがコードが増える）。

## 結果

依存が2つで済む。反面、プロンプト本文に条件分岐を書きたくなったら `string.Template` では
足りず、そのとき Jinja2 の採用を再検討することになる。また `$` を文中に書く場合は `$$`
とエスケープする必要がある。

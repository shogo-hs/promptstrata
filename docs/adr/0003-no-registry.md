# 0003. 版管理は git に任せ、レジストリを持たない

- 状態: 採用
- 日付: 2026-08-22

## 文脈

プロンプト管理ツール（Langfuse・Agenta・PromptLayer）はどれも版管理のためのサーバーと
Web UI を持つ。同じものを作るか検討した。

## 決定

- レジストリ・Web UI・版管理サーバーを作らない。YAML はリポジトリに置き、版は git が持つ。
- 合成結果には `fingerprint`（本文の sha256 先頭12桁）を付け、応対ログからどのプロンプト
  だったかを特定できるようにする。

## 理由

git が既にやっていることを作り直す価値がない。運用で本当に必要なのは「この応対はどの
プロンプトだったか」であって、それは fingerprint 1つで足りる。Web UI が要る規模になったら
Langfuse に載せればよく、そのときもこのライブラリは合成器として使える。

## 結果

サーバーを立てずに使える。反面、非エンジニアが GUI で編集する導線は無い。
